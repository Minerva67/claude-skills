# Claude Skills

自己写、日常在用的 Claude Code skill 合集，按用途分类。单独成仓的 skill 只放链接。

安装：把对应目录复制到 `~/.claude/skills/` 下即可。

| Skill | 用途 |
|---|---|
| [growth-thinking-advisor](https://github.com/Minerva67/growth-thinking-advisor) | 梁宁《增长思维30讲》判断框架 |
| [content-growth-flywheel](https://github.com/Minerva67/content-growth-flywheel) | 社媒有机内容增长六步闭环 |
| [bizmodel-thinking-advisor](growth/bizmodel-thinking-advisor) | 用实战创业者的商业模式结论判断一个生意方向：该不该做、验证到哪、怎么最便宜地证伪 |
| [competitor-teardown](growth/competitor-teardown) | 把竞品拆成带证据的深度报告：公开面→登录态逐路由→付费实测，附可行动清单 |
