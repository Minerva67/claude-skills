# Merge 方法：对标片 × 品牌内容 → 可复现的骨架

## §1 拉片产出物：分幕机制表（不是十节报告）

| 幕 | 时长 | 在干什么 | 机制 |
|---|---|---|---|
| 开场·场景 | 0–7s | 阳光客厅一家人进门；产品第 3 秒才以顶视入画 | 情绪先于产品；上帝视角亮相 |
| Logo 卡 | 8s | 米白底 1s | 硬切标题卡，之后当节奏分隔符复用 |
| 玩法轮转 | 9–23s | 人物全景→顶视桌→手部微距→游戏全屏→表情 | 4 拍循环，每拍≈1s |
| USP 时刻 | 24–31s | 唯一慢下来的 3 秒给差异点 | 慢镜头留给差异点 |
| … | | | |

收敛为 **3–6 个可迁移机制**（写成名词短语，如"顶视是签名镜头"）+ **不能直接搬的原因**
（如"70% 真人正脸/手部/多人群像实拍，我们没有真机"）。

看片要点：Read 每张 montage；文字/数字读单帧；音频不可得就标"推断"。多支视频分角色
（主片学结构情绪，产品短片学微距切法，trailer 学内容画面）。

## §2 品牌内容槽（每条附来源原话）

定位句 ｜ 产品构成（几件套）｜ 技术卖点（参数）｜ 内容阵容（数量 + 名称 + 各自训练点/功能）
｜ 反馈/数据机制 ｜ 受众信号 ｜ CTA/商业信息 ｜ 视觉系统（色值、字体、场景陈设、人物）

**受众核对**是必做项：FAQ 对谁说话、身体/情绪焦虑词指向谁、hero 里谁在用产品、有无年龄
标注。用户的直觉可能和来源相反（曾出现"这是给家长看的吧？"，来源证据全指向成年人自用）。
先摆证据再定，受众决定卖点库排序和真人镜头选谁。

**事实核对**：屏幕上会出现的每个字和数字列白名单，逐条对来源。自己补的计数器数字、
域名、物理细节（线缆有无、接缝）一律删或 `[TBC]`。来源若标 "preliminary"，全片描述
以客户后续给的渲染图为准并写明。

## §3 定性 + 坑位/填法

**一句话定性**模板：
> 一支 {时长}、{节奏}、以 {唯一场景} 为舞台的 {类型}；{谁} 负责情绪，{什么} 负责信息，
> 产品本身 {只出现/被解释}；{唯一的慢镜头/高潮} 留给 {差异点}。
再写一句"不是什么"（不是 UI 演示片 / 3D 旋转片 / 卖点逐条讲的 explainer…）和一条
验收标准（如"关掉字幕和 VO 还应看懂 X"）。

**坑位 → 填法表**：

| 对标片坑位（不变量） | 对标片的填法 | 我们的填法 |
|---|---|---|
| 签名视角 | 顶视桌面 | 顶视板面（脚 + 板 + 地毯） |
| 交互主体 | 手拿棋子 | 脚/重心 |
| 唯一慢镜头 | 实体配件英雄镜头 | 传感/振动可视化 |
| … | | |

只保留 §1 收敛的机制；其余用品牌自己的图形语言。若用户说"太像原片"，删形式留机制：
去掉 1s/拍循环、色卡节拍器、logo 卡开场收尾这类"形式"，留"顶视 = 舞台""慢镜头给差异点"
这类"结构"。

**三个全片不变量**（写进每镜 prompt 头部）：同一场景陈设 / 同一产品描述（尺寸、材质、
无按钮无屏、线缆怎么处理）/ 品牌色只在图形层，实拍层保持自然光。

## §4 复现优先骨架：母版 × 插槽

为什么：真人蒙太奇每一拍单独抽卡，镜头数 = 失败点数；复现性和"像对标片"天然对立，
必须摆到桌面上让用户选，而不是藏在故事板里。

默认骨架（8–10 镜 / 15–30s，可裁 15s / 6s，9:16 同构图）：

| # | 槽位 | 内容 | 生产 |
|---|---|---|---|
| 1 | 插槽 A · Hook | 品牌色满屏一句卖点 hook | CODE |
| 2 | 固定 · 舞台 | 对标片签名视角的**图形化**版本（如顶视板面 + 脚剪影 + 热力图） | CODE |
| 3 | 插槽 B · 卖点展示 | 该卖点的 3–4s 图形表现 | CODE（个别 AE 一次性）|
| 4 | 插槽 C · 真人插片 ① | 从插片池选，2s，可换可删 | DIFF |
| 5 | 固定 · 内容/游戏 | 产品内容画面 + 品牌 UI 元素 | 素材/CODE |
| 6 | 插槽 D · 证据卡 | 与卖点对应的数据/规格芯片标签 | CODE |
| 7 | 插槽 C · 真人插片 ② | 情绪镜头，2s，可换可删 | DIFF |
| 8 | 固定 · 收尾 | logo + tagline + CTA | CODE |

裁切：15s 去 #4 #7；6s = #1 + #3 + #8。

**卖点库**：每个卖点 = hook（插槽 A）+ 图形展示（插槽 B）+ 证据卡（插槽 D）+ 适合的
真人插片。文案来自来源原话或直接改写。首轮投 4–5 支，同结构只换卖点 → 数据差异可归因
到卖点；第二轮赢家做 hook 变体 + "有无真人插片"对照；第三轮扩长或组合。

**真人插片池**：按景别分 5 类模板（顶视脚部/背影看屏/地面微距/侧面反应/环境定场），
每类固定写死场景常量、产品常量、质感常量、负面清单，换动作句即可；每类抽 3–5 条，
出片只看三样（产品形态、有无正脸、肢体是否变形），不合格直接丢不修。

## §5 什么时候不用这个骨架
- 用户明确要"对标片那种真人蒙太奇上限版"给客户看 → 做多镜真人版，但标注复现性低，
  并同时给出骨架版作为"谈下来后能稳定复产"的方案。
- 客户有真机实拍/大量素材 → 真人比例可上调，路由表照用。
